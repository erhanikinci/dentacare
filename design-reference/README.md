# DentaCare Türkiye — Türkçe Ekran Referansları

Bu sürümdeki gerçek arayüz, `app/` ve `src/` altındaki **Türkçe React Native kodlarıyla** oluşturulur.

- `TURKCE_EKRAN_KATALOGU.png`: 23 ekranın Türkçe, **şematik** görsel haritası (emülatör ekran görüntüsü değildir).
- `SCREEN_MANIFEST.json`: Türkçe ekran adları ve Expo Router yolları.
- `PREVIEW_Turkce_Splash.png` (projenin kökünde): Türkçe Splash için görsel tasarım önizlemesi; gerçek uygulama Splash animasyonu `app/splash.tsx` içindedir.

Önceki İngilizce yüksek çözünürlüklü tasarım görselleri, **tamamen Türkçe bir proje paketi** oluşturmak için bu sürüme dahil edilmedi. Uygulamanın çalışması için gerekli herhangi bir görsel çıkarılmadı; kullanılan resimler `assets/` ve vektörel illüstrasyon kodları içindedir.
